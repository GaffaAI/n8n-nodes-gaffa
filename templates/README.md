# Workflow templates

Templates for n8n's template library, one folder per template, each holding the workflow JSON and a README with the text users see on the template page.

The n8n Creator Dashboard takes only the workflow JSON, so the sticky note inside the workflow carries everything a user sees before import. The README mirrors that sticky text so it can be reviewed here.

Every template is tested end to end on a local n8n with the published node installed from npm before it goes anywhere.
